# QCチェックリスト(全42カット)

## 構図・映像

- [ ] キャラ・黒板・字幕が重なっていない(字幕セーフエリア: 下部480px)
- [ ] 黒板の文字・図形が1080px幅で可読(スマホ実寸で判読可能なサイズ)
- [ ] パララックスでレイヤー境界の欠け・後光(白フチ)が見えない
- [ ] カメラ移動が一方向・一種類で、イージングが唐突でない
- [ ] 同一ショットサイズが3カット以上連続していない

## 口パク・キャラ

- [ ] 発話中のみ口が動き、無音区間で閉口している
- [ ] visemeが音とずれていない(±2フレーム以内)
- [ ] 目パチが3〜5秒間隔で入り、話者切替時に不自然な静止がない

## 字幕

- [ ] カラオケハイライトが音声と同期している
- [ ] 改行が文節境界で、1行13文字以内
- [ ] 話者色が正しい

## 音

- [ ] セリフ頭が切れていない(パディング0.35s確保)
- [ ] BGMがセリフ中に沈み(ダッキング)、無音カットで戻る
- [ ] 統合ラウドネス -14 LUFS ±0.5(WAVマスター・納品AACとも)
- [ ] トゥルーピーク: **検収ゲートは納品AAC(final-master.mp4)-1.0 dBTP以下のみ**。WAVマスター(out/master-audio.wav)の-1.5 dBTPはmix内部ターゲットの参考値であり、単独では不合格としない(目安: -1.3超で mixパラメータ見直しを起票)。基準の根拠は cto-handoff.md ADR-9

## 全体

- [ ] 60fps再生が滑らか(レンダリング後のmp4で確認)
- [ ] シーン間の場面転換で違和感がない
- [ ] 総尺がショート動画として成立(目安3分以内。超える場合は報告)
