# QC検分手順書(docs/qc-checklist.md 18項目 × 実行手順)

**この文書の目的**: `docs/qc-checklist.md`の各項目を「何を・どう測って・何が合格か」まで機械的に実行できる形に落とし込む。
QC-Inspector Agentは判定基準を自分で設計しない。ここに書かれた手順通りに実行し、記録するだけでよい。

## 0. 共通ルール(全項目に適用)

- **判定に自信が持てない項目は「合格/不合格」ではなく「要Tech Lead確認」と記録する**。推測で合格にしない(cto-handoff.md §17.2-1)。
- **stillのフレーム番号は `docs/qc-report.md` 冒頭のフレーム早見表(F0-1で生成)の現行値を使う**。旧い値(cto-handoff.md §14)は使わない。
- 各カットの head/mid/tail フレームは次の式で計算する: `head = from` / `mid = from + floor(dur/2)` / `tail = from + dur - 1`。秒への変換は `frame / 60`。
- **Pythonスクリプト(probe.py / contactsheet.py / mouthpatch.py / fixbg.py / cutout.py)は必ず `python` コマンドで実行する。`.venv/Scripts/python.exe` は align.py(Whisper)専用の別環境で、Pillow/numpyが入っておらず動かない。**
- still生成: `npx remotion still Main --frame=<F> --output=out/qc-<cutId>-<head|mid|tail>.png`(コンポジションID=`Main`)
- 座標裏取り: `python pipeline/probe.py <画像パス> <x1> <y1> [<x2> <y2> ...]`
- 合成プレビュー: `python pipeline/contactsheet.py <出力パス> <画像1> <画像2> ...`

## 2. 項目別 手順

### 構図・映像

**1. キャラ・黒板・字幕が重なっていない(セーフエリア: 下部480px = y≥1440、画面1080×1920)**
1. セリフ表示中のフレーム(mid推奨)のstillを生成。
2. y=1440〜1919の帯にキャラの体・黒板描画がはみ出していないか目視。
3. 微妙なら `probe.py` でy=1440付近、疑わしいx座標2-3点をサンプリングし背景色でないか確認。
- 合格: 帯にキャラ/黒板要素の重なりなし。不合格: 明確に重なっている。

**2. 黒板の文字・図形が1080px幅で可読**
1. `board.visible=true` のカットの、黒板描画が最も進んだフレーム(tail推奨)のstillを生成。
2. 1080×1920のまま(拡大せず)表示し、黒板内の文字・図形が読めるか確認。
- 合格: 実寸で判読可能。不合格: 潰れて読めない。

**3. パララックスでレイヤー境界の欠け・後光(白フチ)が見えない**
1. `camera.parallax` が動くカットのhead/mid/tail 3枚のstillを生成。
2. `contactsheet.py` で1枚にまとめ、キャラ・前景レイヤーの輪郭を目視。
- 合格: 欠け・白フチなし。不合格: 輪郭に白フチ/背景の切れ目が見える。

**4. カメラ移動が一方向・一種類で、イージングが唐突でない**
1. `out/final-master.mp4` を該当秒範囲(`from/60`〜`(from+dur)/60`秒)で再生。
- 合格: 一方向・一種類の動き、速度変化が滑らか。不合格: 逆走・複数方向混在、急停止/急発進。

**5. 同一ショットサイズが3カット以上連続していない**
1. 対象シーンの `video.json` `cuts[].camera.shot` を先頭から並べる。
- 合格: 同一shot値が3カット以上連続していない。不合格: 3カット以上連続。

### 口パク・キャラ

**6. 発話中のみ口が動き、無音区間で閉口している**(無音カットはN-A)
1. 該当カットを再生し、`dialogue` の発話区間と `pauseAfterSec` 区間での口の開閉を確認。
- 合格: 発話中のみ開閉、無音区間で閉口。不合格: 無音区間でも動く、または発話中に閉口したまま。

**7. visemeが音とずれていない(±2フレーム以内)**(無音カットはN-A)
1. `public/alignment/<lineId>.json` のタイムスタンプと、該当フレームのstillでの口形を比較。
2. 1行につき母音の切り替わり地点を1〜2箇所サンプリング。
- 合格: ズレ2フレーム以内。不合格: 明確なズレ。

**8. 目パチが3〜5秒間隔で入り、話者切替時に不自然な静止がない**
1. 該当カットを再生し、目パチ間隔と話者切替時の動きを確認。
- 合格: 間隔が概ね3〜5秒、不自然な静止なし。不合格: 極端に短い/長い、切替時に停止して見える。

### 字幕(無音カットは9/10/11 すべてN-A)

**9. カラオケハイライトが音声と同期している**
1. 該当カット再生し、ハイライトの進みと発話音を同時確認。
- 合格: 同期。不合格: 明確なズレ。

**10. 改行が文節境界で、1行13文字以内**
1. `video.json` `subtitle.lines[].displayText` を読み、各行の文字数と改行位置を確認。
- 合格: 全行13文字以内かつ文節境界。不合格: 超過 or 文節を割っている。

**11. 話者色が正しい**
1. `video.json` `meta.speakerColors` と、該当カットstillの字幕色を比較。
- 合格: 一致。不合格: 不一致。

### 音(無音カットは12/13がN-A、14/15は全編共通のため後述)

**12. セリフ頭が切れていない(パディング0.35s確保)**
1. 該当カット頭を再生し、セリフの出だしが欠けていないか耳で確認。
- 合格: 欠けなし。不合格: 最初の音が切れて聞こえる。

**13. BGMがセリフ中に沈み(ダッキング)、無音カットで戻る**
1. 該当区間を再生し、セリフ中のBGM音量低下と、無音カットでの復帰を耳で確認。
- 合格: ダッキングと復帰が機能している。不合格: 沈まない/戻らない。

**14. 統合ラウドネス -14 LUFS ±0.5(全編共通・カット単位ではない)**
```
ffmpeg -nostats -i out/master-audio.wav -af ebur128=peak=true -f null -
ffmpeg -nostats -i out/final-master.mp4 -af ebur128=peak=true -f null -
```
- 合格: 両方とも I = -14.0 ±0.5 LUFS。不合格: 範囲外。

**15. トゥルーピーク(全編共通)**: **検収ゲートは納品AAC ≤-1.0 dBTPのみ**。WAVマスターの-1.5は参考値・非ゲート(tech-lead-plan.md TL-2、根拠ADR-9)。
- 上記14と同じffmpegコマンドのTP値を確認。合格: AAC側TP≤-1.0。WAVが-1.3を超えていたら参考記録として報告(不合格にはしない)。

### 全体(カット単位ではなく全編で1回のみ記録)

**16. 60fps再生が滑らか**
1. `out/final-master.mp4` を等速再生し、カクつき/フレーム落ちがないか確認。
- 合格: 滑らか。不合格: カクつき視認。

**17. シーン間の場面転換で違和感がない**
1. 各シーン境界(s1末尾→s2先頭 など、6箇所)を再生。
- 合格: 違和感なし。不合格: 違和感あり(具体的にどう感じたか記述)。

**18. 総尺がショート動画として成立(目安3分以内。超える場合は報告)**
```
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1 out/final-master.mp4
```
- 既知値303.9s(3分=180sを超過)は**仕様上の確定尺**(cto-handoff.md §2)。判定は「303.9s、3分超過だが確定仕様」と記録するのみでよく、対応不要。
