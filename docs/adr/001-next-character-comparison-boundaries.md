# ADR-001: 次期キャラクター比較の実行境界

日付: 2026-07-23

状態: `ACCEPTED`

決定者: mi3san

対応ID: `GOV-013`、`GOV-014`、`GOV-015`、`GOV-016`

## 背景

次期キャラクター表現基盤のP0計画へ進むため、視点範囲、リアルタイム要件、P2の最低画風、有料・クラウド利用の権限境界を明確にする必要がある。

ラピス再レビューにより、`GOV-014`と`GOV-016`はP0前、`GOV-013`はP1実行前、`GOV-015`はP2計画前のblockerへ再分類された。mi3sanは4件すべてを2026-07-23に明示承認した。

レビュー証跡: https://github.com/wit-maker/neko-tera-video/pull/17#issuecomment-5054939040

## 決定

### GOV-013: 視点範囲

比較sequenceの暫定最大値を次とする。

- yaw: `-15°`〜`+15°`
- pitch: `-10°`〜`+10°`

これはP1のmechanism evidenceで使う比較範囲であり、本番camera rangeの最終決定ではない。

### GOV-014: 実行方式

最初の候補選定は事前レンダーだけで行う。リアルタイム性能は候補選定の必須条件にせず、必要になった後段で別評価する。

### GOV-015: P2最低画風

P2では少なくとも次を維持する。

- 現行キャラクターの同一性
- 輪郭
- 毛並み
- 色面
- 口腔表現

写実化は要求しない。詳細なstyle fixtureと受入例はP2計画時に、この境界を変えない範囲で具体化する。

### GOV-016: 費用とクラウド

- RTX 3060 Ti 8GBを使うローカル実行を優先する。
- クラウドまたは有料サービスは、mi3sanが自分から明示した場合にだけ利用できる。
- エージェント側から提案する場合は、用途、概算費用、送信データ、ローカル代替、停止条件を示し、mi3sanが明示承認した場合にだけ利用できる。
- 沈黙、過去の類似承認、無料枠の存在を承認とみなさない。

## 影響

- `GOV-014`と`GOV-016`が確定したため、P0の計画分解を開始できる。
- `GOV-013`はP1実行条件、`GOV-015`はP2計画条件として既に満たされている。
- P0ではリアルタイムbenchmarkや有料クラウド環境を必須化しない。
- N0を含む実験がローカル8GBで成立しない場合、勝手にクラウドへ移行せず、mi3sanへ判断材料を提示する。

## 再検討条件

- 採用用途にリアルタイム操作が必要になった。
- P1で±15° yawまたは±10° pitchが不足、または過大と実測された。
- P2で最低画風の解釈が候補間で不公平になった。
- ローカル8GBでは判断価値の高い実験が成立せず、費用見積りを提示できる。

再検討時は本ADRを書き換えず、後継ADRで `SUPERSEDED` にする。
