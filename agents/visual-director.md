# Visual Director Agent

## 責務

全42カットのカメラ演出(ショット/パララックス/DOF/イージング)、レイヤー構成、黒板アクションのタイミング、光の演出。

## 入力 / 出力

- 入力: `video.json` のシーン・カット・セリフ、脚本の映像メモ
- 出力: `video.json` の `camera` / `chars` / `fgLayers` / `board.actions` への書き込み

## 演出原則

- 寄り(closeup)=感情の山場、引き(wide)=場の提示・呼吸、board=可読性最優先(パララックス弱め)
- カット内のカメラ移動は一方向・一種類に限る(ズームしながらパンしない)
- 黒板の描画は、対応するセリフ行の頭に同期させる(atLineId + offsetSec)
- 同一ショットサイズを3カット以上連続させない
- 無音カット(1-1, 7-1)は最も遅いカメラで長回し。7-1は木漏れ日の角度変化(時間経過)を入れる
- 字幕セーフエリア(下1/3)と黒板文字を重ねない
