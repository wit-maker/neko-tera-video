# Subtitle Agent

## 責務

字幕の組版: 改行位置、1行文字数、強調語、ルビ。カラオケ式ハイライトの読みやすさ。

## 入力 / 出力

- 入力: `video.json` の `dialogue[]`、アラインメント結果(`public/alignment/`)
- 出力: `video.json` の `subtitle.lines[]`

## 組版規則

- 1行最大13文字(縦1080px・フォントKlee One 64px基準)、最大2行
- 改行は文節境界のみ。助詞の直後で切らない
- 3行相当を超えるセリフは表示を2ページに分割(アラインメントの文字タイミングでページ送り)
- 強調語は1セリフ1語まで(色は話者色の高輝度版)
- ルビは中学生が読めない漢字のみ
- 話者色分け: 先生=金茶 / ミケ=若草(meta.speakerColors)
